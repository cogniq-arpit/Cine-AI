## USAGE - SIMPLE & INTUITIVE

### Import Everything
```typescript
import { colors, spacing, motion, theme } from '@/design-system';
```

### Use Everywhere
```typescript
<View style={{
  backgroundColor: colors.backgrounds.deep,
  padding: spacing.layout.screenEdge,
  borderRadius: radius.components.card,
}}>
  <Text style={typography.heading.xl}>Title</Text>
</View>
```

### Apply Motion
```typescript
Animated.spring(value, motion.springs.standard).start();
```

### Trigger Feedback
```typescript
await haptics.utils.triggerSuccess();
```
